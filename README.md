# My blog website

Source for [andsav.dev](https://andsav.dev) blog website.

Once cloned, make sure to run `git submodule update --init --recursive`

## What open source tools I used to build this?

* Static website generator [Hugo](https://gohugo.io/overview/introduction/)
* Theme [PaperMod](https://github.com/adityatelange/hugo-PaperMod)

## Credits

I learned the idea of how to build a markdown-based blog website from [Bartlomiej Plotka](https://github.com/bwplotka/my/). Thanks man!
